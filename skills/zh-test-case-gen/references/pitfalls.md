# Pitfalls：zh-test-case-gen

## [2026-10] 只有 happy path

- 症状：10 条用例全是合法输入，一上线就被空串和负数打崩。
- 正确处理：每类输入域强制产出至少 2 条异常用例，写不出异常就说明输入域分析不够。

## [2026-10] 边界只测单侧

- 症状：测了 `quantity=1` 没测 `quantity=0`，漏掉 `min-1` 的 off-by-one。
- 正确处理：边界三连（min-1/min/min+1），max 同理。

## [2026-10] mock 掉被测逻辑

- 症状：为了「隔离依赖」把内部子函数也 mock 了，用例通过但真实路径从未被执行。
- 正确处理：mock 只作用于 I/O 边界（网络/时钟/随机），内部逻辑保持真实。
