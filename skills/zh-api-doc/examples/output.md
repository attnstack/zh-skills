## POST /v1/orders

创建订单。需登录态；同一买家对同一 SKU 的重复提交在 3 秒内幂等（返回同一订单）。

### 请求参数

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| sku_id | string | 是 | 商品 SKU 编号 | `"1000238"` |
| quantity | integer | 是 | 购买数量，1-999 | `2` |
| remark | string | 否 | 买家备注，≤200 字符 | `"尽快发货"` |

### 响应

| 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|
| order_id | string | 订单号（待确认具体格式） | `"20261030123456"` |
| created_at | string | 创建时间，ISO8601，UTC | `"2026-10-30T08:00:00Z"` |

### 错误码

| code | 含义 | 处理建议 |
|---|---|---|
| 400 | 参数错误（如 quantity 超界） | 按 message 提示修正后重试 |
| 401 | 未登录 | 引导用户登录后重试 |
