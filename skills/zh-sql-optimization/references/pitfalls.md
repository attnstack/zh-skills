# Pitfalls：zh-sql-optimization

## [2026-10] 联合索引只说「加索引」

- 症状：建议里没有列顺序，DBA 按任意顺序建完，filesort 依旧。
- 正确处理：等值列在前、范围/排序列在后，并解释为什么这个顺序能让排序走索引。

## [2026-10] 隐式类型转换被忽略

- 症状：`WHERE phone = 13800138000`（phone 是 VARCHAR），数字字面量导致索引失效，
  建了索引也没用，回炉排查半天。
- 正确处理：先检查字面量类型与列类型是否一致，再谈索引。

## [2026-10] 用缓存掩盖慢查询

- 症状：「加个 Redis 就快了」——数据一变脏读，根因仍在。
- 正确处理：缓存是容量手段，慢查询先修到可接受，再谈缓存。
