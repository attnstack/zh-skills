# Pitfalls：zh-readme-gen

## [2026-10] 安装命令与实际包管理器不符

- 症状：README 写 pnpm add，仓库只有 package-lock.json，用户跑完报错。
- 正确处理：命令前先看锁文件与 package.json scripts；两者冲突时按锁文件为准。

## [2026-10] 特性表全是形容词

- 症状：「高性能」「简单易用」「功能强大」——没有一条可验证。
- 正确处理：每条特性写「做什么 + 验证方式」，性能写数字并给 benchmark 命令。

## [2026-10] 首屏堆原理

- 症状：用户想跑起来，却要先滑过 500 字架构介绍。
- 正确处理：一句话定位 + 上手命令放最前，原理放二级标题之后。
