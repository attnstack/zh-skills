# Pitfalls：zh-weekly-report

## [2026-10] 流水账周报

- 症状：逐条罗列 commit（fix typo ×5 也占一行），读者找不到重点。
- 正确处理：commit 只当素材，按「里程碑级结果」归并，佐证数字放括号里。

## [2026-10] 风险节写「一切正常」

- 症状：没有验证依据的「正常」，领导默认你没暴露问题，出事后追责反而更重。
- 正确处理：要么写「无 + 验证依据」，要么写真风险 + 需要的支持。

## [2026-10] 未完成事项消失

- 症状：上周计划里的 3 件事这周只剩 2 件，未完成的那件悄悄不见了。
- 正确处理：未完成事项显式写「未完成 + 原因 + 新预期时间」。
