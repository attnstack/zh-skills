# Pitfalls：zh-typography

使用中发现的真实反例。新增条目用 `zh-skills learn zh-typography <file>` 或直接提 PR。

## [2026-10] URL 内的标点被误转全角

- 症状：`https://example.com/a?b=1` 中的 `?` 被替换为 `？`，链接失效。
- 原因：把「中文语境」理解成了「整行含中文」，而不是「标点紧邻 CJK 字符」。
- 正确处理：标点转换只看左右紧邻字符是否为 CJK；URL 前后有中文时先补空格再判断。

## [2026-10] 时间冒号被误转全角

- 症状：`12:30` 变成 `12：30`，与中文习惯的时间写法冲突。
- 正确处理：冒号两侧均为数字时保持半角。

## [2026-10] Markdown 表格分隔线被当作正文处理

- 症状：`|---|---|` 被加空格/改标点，表格渲染失败。
- 正确处理：表格分隔行、代码围栏内、内联代码内整段跳过。
