# 中文排版校对

对中文（或中英混排）文本做**规则化**排版修复。所有规则可被脚本判定，输出可复现。

## 工作流程

1. 若本 skill 目录下存在 `scripts/`，优先用脚本处理（结果确定、可回归）：
   ```bash
   # 修复：stdin 进 stdout 出
   node scripts/fix.mjs < 输入文件 > 输出文件
   # 检查：只报告违规行号，不改文本（适合 CI 门禁）
   node scripts/check.mjs < 输入文件
   ```
2. 无脚本环境时，按下方「规则清单」逐条人工应用。
3. 输出前用 `scripts/check.mjs` 自检，确认 0 违规再交付。

## 规则清单

| # | 规则 | 错误示例 | 正确示例 |
|---|---|---|---|
| 1 | 全角字母/数字转半角 | ＲＥＡＤＭＥ、２０２６ | README、2026 |
| 2 | 中文语境半角标点转全角（`,;!?` 与 `:`） | 你好,世界 | 你好，世界 |
| 3 | CJK 与 ASCII 字母/数字之间加一个半角空格 | 使用Node.js开发 | 使用 Node.js 开发 |
| 4 | 连续 `！`/`？` 压缩为单个 | 真的吗？？ | 真的吗？ |
| 5 | 删除行尾空白 | `hello␣␣` | `hello` |

**规则 2 的例外**：时间（`12:30`）与两侧均为数字的键值场景不转全角冒号。
**规则 3 不适用的位置**：Markdown 语法符号（`**`、`` ` ``、链接方括号）与 CJK 的关系不调整；
表格分隔线、代码块内部一律不动。

## 判定边界（什么时候不处理）

- 代码块（``` 围栏内）整块跳过；
- 内联代码（反引号包裹）内部跳过；
- 纯英文行（无 CJK 字符）跳过；
- 只判断「形式正确」，不改写措辞——语义问题转告用户而不是擅自修改。

## 输出格式

- 修复类任务：给出修复后全文 + 一行变更摘要（如「5 处标点、3 处间距」）；
- 检查类任务：逐行列出 `行号: 问题`，最后给总数。

## 常见错误

处理前先读 `references/pitfalls.md`，特别是：URL 中的标点误转、全角波浪号 `～` 被误判、
中文引号嵌套场景。遇到「规则没有覆盖的排版分歧」，按 GitHub 中文文案排版指北的默认值处理，并在回复中说明。
